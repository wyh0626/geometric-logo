# 方法：从 Rikyu 样张反推的几何构图法

rikyu.ai 是一个 AI 设计代理：用自然语言描述需求，它产出 logo、海报、网页、贴纸和短视频，
还可以通过 MCP 接入 Claude、Cursor、Codex。官网没有公开构图方法。下面的规则是从它发布的
"构图卡 + 成品"样张，以及几组 before/after 对比图里归纳出来的。本 skill 的脚本就按这些规则实现。

## 1. 两件产物与卡片的视觉语法

**成品 mark**：单一深橄榄色（约 #45463A）的平面剪影，放在暖米白底（约 #F3F0E7）上，居中，
大面积留白（mark 约占画面宽度的 35–45%）。没有描边、渐变和文字。

**构图卡**（4:5 竖版）从上到下分为：
- 顶部居中是品牌标识。本 skill 改用"成品缩小版 + title"，不使用任何他人的品牌。
- 上部约 75% 是方格纸：细网格加上每 5 格一条稍深的主线。网格向下渐隐到底色。
- 构造图分三层：
  1. 形状本体：浅暖灰实填，不用黑色，这样构造线在它上面也看得清；
  2. 构造圆：细灰线、不填充，大量互相叠压，常常超出画面边缘；
  3. 直线：切线和基准线贯穿全幅，圆心画小十字，半径线端点画小圆点，对称轴用虚线。
- 左下是 CONCEPT 小标签（大字距）和 1–3 句概念说明。
- 右下是贴着外框的方框，里面放深色成品缩略图。

构图卡在视觉上是"证明"：它让观者相信每一段轮廓都有来由。

## 2. before/after 揭示的核心规则

Rikyu 公开过四组同一图标的前后对比（相机、章鱼、自行车、火箭）。差别不在成品的大致样子，
而在**构造是不是形状的来源**。

| | Before：先画后套 | After：先构造后得形 |
|---|---|---|
| 圆与轮廓 | 圆是事后套上去的，只和轮廓大致贴合 | 每段弧轮廓都是某个构造圆的一段，圆心可以标出 |
| 半径 | 大小杂乱，种类很多 | 种类很少，同一半径反复出现 |
| 对齐 | 随意 | 水平基线、中轴、同心、等距 |
| 直线 | 贝塞尔锚点和手柄 | 切线和基准线，延长到画面边缘 |
| 说服力 | 装饰性网格 | 可验证的推导 |

逐个看：
- **相机**：机身四个圆角是四个等半径的角圆，构造图里能看到完整的四个圆。镜头是一组同心圆，
  深浅相间、宽度相同。顶钮的侧边和机身的上下沿共用几条水平和竖直基准线。
- **章鱼**：头是一个大圆，两只眼是同一水平线上的两个等圆。触手左右镜像，
  每条触手由相切的圆弧串成，半径逐级缩小，最后卷成螺旋。
- **自行车**：前后轮是等大的圆环，车架是连接轮心的直线。骑手是一个圆头加一组平行斜线，
  斜线同时交代姿态和速度感。
- **火箭**：所有部件落在一根竖直中轴上。机身是两个大圆相交得到的 vesica（鱼形），
  两侧尾翼由另外两组圆弧切出，火焰是一个小 vesica。

**结论**：要让模型直接写"构造"，再由程序从构造计算轮廓，而不是让模型画贝塞尔曲线、
再给它配几何图。本 skill 的 JSON 规格就是这层约束：形状只能由图元和布尔运算得到，
构造线由同一批图元自动生成，两者不可能对不上。

## 3. 动物与家纹样张的手法

- **剪影优先**：动物用一整块实心剪影表达，内部不画细节线。
- **负空间沟槽**：前景部件（前臂、后腿、尾巴、一片鬃毛）和后景体块之间留一条**等宽**的米白缝。
  全图只用一种缝宽，约为 mark 宽度的 2–3%。做法是画家算法：后画的部件先在已有墨迹上挖出
  "自身外扩一个缝宽"的区域，再把自己填进去。对应 ink 的 `{"add": X, "gap": g}`。
- **地面线**：行走的大猩猩、踩石的狮子都有一条明确的水平地面线，所有着地点都落在上面，
  重心稳定。实现方法是最后切掉地面线以下的部分。
- **体块是圆**：躯干、肩、臀、头各是一个大圆。四肢是两圆的凸包（外公切线构成笔直的肢体轮廓），
  关节用小圆过渡。
- **鬃毛、羽毛、火焰**：重复的 lune（两条圆弧夹出的尖叶形），绕一个中心或沿一条弧排列。
- **卷曲**：黄金螺旋，即每转 90° 半径乘 1/φ 的相切圆弧链。家纹里天马的鬃毛就是一个螺旋涡。
- **家纹（kamon）**：一个外环加内部图案。图案可以不对称（前腿扬起、翅膀张开），
  但整体重量要在圆内平衡。图案与外环之间要么用同一个缝宽断开，要么直接相接成一体。

## 4. 比例系统

- **一个模数**：选一个基本单位 U（常用缝宽，或最细部件的宽度），其他尺寸取 U 的整数倍。
- **半径族**：R, R/φ, R/φ², …，或 1:2:3:5。目标是 5 种左右。`report.txt` 会列出实际用到的半径。
- **点的来源**：关键点要么落在 0.5 网格上，要么由几何推出（切点、交点、`polar`、`on`）。
  推导出来的点不在网格上没关系，它本身就是构造的一部分。
- **对称**：物件类优先严格左右对称（`mirror`）。侧身的动物不对称，但要有清楚的基线和主轴。
- **常用推导公式**：
  - vesica：两圆半径 R、圆心距 2d，则半宽 w = R − d，半高 h = √(R² − d²)；
    反过来，已知 w、h 时 R = (h²/w + w)/2，d = R − w。
  - 圆弧拱高：弦长 2c、半径 r 时，拱高 s = r − √(r² − c²)；已知拱高时 r = (c² + s²)/(2s)。
  - 两圆外切：圆心距 = r1 + r2；内切：圆心距 = |r1 − r2|。

## 5. 从概念到构造：配方

| 母题 | 构造 |
|---|---|
| 圆形物件（相机、钟、碗） | 圆角矩形 + 同心环；附件落在角圆圆心或基准线上 |
| 尖头物件（火箭、钢笔、船头） | 两圆相交的 vesica，竖直中轴，左右镜像 |
| 植物（叶、花、麦穗） | lune 叶片 + `repeat` 或沿弧排列；叶脉用细 `stroke` 挖出 |
| 水与火（浪、火焰、水滴） | 圆弧链与 lune；浪尖用螺旋 |
| 坐姿动物（猫、狗、兔） | 臀部大圆贴地面线，胸部和头部依次叠在上方，比例取 φ；前腿是竖直 stroke；大腿处用一条沟槽分开 |
| 行走动物（熊、猩猩、马） | 肩、臀两个大圆，hull 出背线；四肢是两圆的 hull，前景肢体加 gap；切地面线 |
| 鸟 | 身体是 vesica 或大圆，翅膀是同号 lune，尾巴是 lune 扇形，喙是小三角 poly |
| 海洋生物（章鱼、鲸、鱼） | 头或身体是大圆，触手和尾巴是渐细的 turtle 加螺旋 |
| 徽章 / 家纹 | 外环 `ring`，内部用 `repeat`（花、齿轮）或一个不对称剪影，缝宽统一 |
| 字母组合 | 圆和环的分段：`sector`、`arc`；直笔用 `stroke` |

## 6. 质量门槛

- 32px 仍可识别，16px 至少保留轮廓（看 `sizes.png`）。
- 没有细于 `min_feature` 的部位，没有窄于 `min_gap` 的缝，没有孤立碎片（看 `report.txt`）。
- 半径不超过 6 种，缝宽只有一个值。
- 视觉重心接近中心；站立的物体有地面线。
- 单色、无渐变、无描边、无文字。负空间要参与造型。
- 构造图里每个圆都"有用"：它要么定义了一段轮廓，要么定义了一个关键点。没用的圆宁可删掉。

## 7. 复杂动物：一次迭代复盘（大猩猩，13 版）

这只大猩猩没有收进示例，但中间走过的弯路比结论更有用（坐姿动物的完整示例见 `examples/seal.json`）：

| 版本 | 做法 | 看起来像 | 原因 |
|---|---|---|---|
| v1–v4 | 每段肢体是两圆的 hull，背是一条直切线 | 熊、大象 | 四条柱子腿；背太平；头只是一个圆，没有物种特征 |
| v5–v9 | 整个轮廓用 `chain` 绕小圆 | 机器人、木板 | 小圆配长切线就是圆角多边形；凸圆没伸出切线，轮廓鼓成球 |
| v10 | 每块体积是一串相交圆加 `blend` | 气球动物 | 每个圆都是一个鼓包，圆与圆之间是凹口 |
| v11–v13 | 肢体用 hull，背和前臂叠浅 lune，凹角用小 blend，头加颅顶/眉骨/吻部，前臂后缘一排毛簇 | 大猩猩 | 轮廓干净；大弧和直边比例对；物种特征都在 |

由此得到的规则：
1. **先想剪影的"笔画"**：哪些边是长而干净的（肢体前后缘、背），哪些是短而圆的（关节、手脚、头）。
   长边用切线，或者叠一个浅 lune 鼓出弧；短边用圆。
2. **轮廓要有节奏**：大块凸弧（肌肉）→ 收束（腕、踝，小圆或凹圆）→ 再展开（手、脚）。
   每段肢体都应该有这个节奏，否则就是柱子。
3. **物种识别靠 3–4 个特征**：比例（大猩猩前重后轻、肩高于臀）、头部轮廓、一个质感符号
   （毛簇、鬃毛、斑纹的剪影化表达），以及姿态（指节着地）。特征比细节数量重要。
4. **层次只用一种缝宽**，而且每条缝都要从外轮廓通到一块负空间，不要在体块内部围成封闭的圈。
5. **远侧肢体**只在前景肢体之间露出一条，位置要避开毛簇和手脚，否则会被 gap 切成碎片。
6. **每轮只改一两处**，同时看 poster（整体）和 sizes（32px 能否识别）。保留每一版 spec，退步就回滚。

## 8. 对照 Rikyū 的实际产物（反算导出的 SVG）

### 它有两条路线

| | 几何 logo | 自由矢量 |
|---|---|---|
| 用于 | 抽象图形、1–3 个字母的组合字标、简单动物和物件 | 龙这类复杂题材、部分字标、插画 |
| 生成方式 | 先选圆和直线，布尔合并后导出贝塞尔 | 交给 QuiverAI Arrow（SVG 生成模型） |
| SVG 特征 | 绝对坐标（M/L/C），三位小数；**每段曲线都是精确圆弧** | 带 `created with Arrow, by QuiverAI` 注释；相对坐标；数值全落在 0.128 网格上（坐标被量化成 token） |
| 构图卡 | 有，就是构造本身 | 没有 |

总控 agent 按题材挑设计准则（徽章构图、题材取舍、画法统一），写 brief，最后对照用户要求评审。
**走哪条路取决于题材复杂度和措辞**：提示词里写"只用圆、圆弧和直线"、"给出构造图"会走几何路线；
写"流动的身体、鳞片、云纹"会走 Arrow。

### 它的几何 logo 有多"省"

| 指标 | 它的猫 | 它的大猩猩 | 我们的海豹（seal.json） |
|---|---|---|---|
| 轮廓中精确圆弧的比例 | 100% | 100%（38/38） | 64% 圆弧、30% 直线、6% 折线（尾鳍和鳍的 lune 尖端） |
| 直线段 | 4（耳朵） | 35（四肢和背的切线） | 身体和头部的切线 |
| 不同的圆 | 约 9 | 18 | 19（卡上显示的） |
| 半径种类 | 约 7 | 9 | 偏多 |
| 半径复用 | 300.6 用了 3 次（不同圆心） | 146.8 / 123.0 / 59.0 各用 3 次 | 有，但不够集中 |
| 缝的做法 | — | 同心圆：99.3 与 110.4 同心，110.4 与 123.0 同心，半径差就是缝宽 | `gap`，构图卡上同样画成同心圆 |

### 结论

- 它的几何 logo 和我们构造模式的方法相同：圆，加上两圆之间的公切线，布尔合并，用同心圆做等宽缝，再对齐地面线。
  没有别的秘诀。
- 它的成品比我们"省"：圆更少、半径复用更多、不用倒角平滑。所以每段曲线都能指认出来源。
  我们要向这个方向收：主体积的半径成族复用，用显式小圆代替 blend，让 `report.txt` 里的折线占比接近 0。
- 它的几何大猩猩其实相当"方"，四肢是直的梯形，脚是平台。宣传图那只更精致的，可能是挑出来的最好结果，
  或者来自早期另一套流程。不要把宣传图当成这条路线的平均水平。
- 复杂题材它也不硬做几何，而是交给 Arrow，而且不出构图卡。本 skill 同样只做几何，复杂题材请用户简化或另找工具。
