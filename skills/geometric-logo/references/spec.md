## 1. 文件结构与顶层字段

JSON 文件，允许 `//` 注释和末尾逗号。

```jsonc
{
  "name": "octopus",          // 输出目录名（默认取文件名）
  "title": "Octopus",         // 卡片顶部标题（品牌名），配一个小号的成品 mark
  "concept": "一到三句话…",    // 卡片左下的说明，中英文都会自动换行
  "label": "CONCEPT",         // 说明上方的小标签
  "header": true,             // false 时不画顶部标题
  "size": 100,                // 画板边长（设计单位），默认 100
  "vars":   { … },            // 数值，按书写顺序求值，可以互相引用
  "points": { … },            // 命名点
  "shapes": { … },            // 命名图形
  "ink":    [ … ],            // 必填：最终墨迹的绘制步骤
  "guides": [ … ],            // 可选：只画在构图卡上的额外构造线
  "soften": 0.6,              // 可选：最后给整体所有拐角统一倒圆（倒角弧不是构造圆，icon.svg 里会写成折线）
  "show": "key",              // 构图卡画哪些构造："key"（默认，只画落在最终轮廓上的）或 "all"
  "backdrop": {"shape": "tile", "color": "#FFFFFF"},      // 可选：画在墨迹下面的底，如 App 图标的圆角方块；可以是列表
  "paint": [{"shape": "back", "color": "#2AA3DE"}],       // 可选：多色。墨迹与该图形相交的部分改用这个颜色，按顺序叠加
  "colors": {"ink": "#45463A", "paper": "#F3F0E7"},
  "min_feature": 2,           // 体检阈值：最细部位（默认 size*0.02）
  "min_gap": 1.2              // 体检阈值：最窄缝（默认 size*0.012）
}
```

`vars`、`points`、`shapes` 共用同一个命名空间，名字不能重复。

## 2. 坐标、角度、表达式

- 画板 0..size，**y 轴向下**（SVG 约定），中心是 `(50, 50)`。
- 角度用**度**：0° 指向右、90° 指向下、180° 指向左、−90°（或 270°）指向上。
  角度增大是屏幕上的**顺时针**方向。
- 凡是数值的位置都可以写表达式字符串，例如 `"R/phi"`、`"cx + W/2 - Rc"`、`"sqrt(R*R - d*d)"`。
  - 常量：`phi`（黄金比 1.618…）、`pi`、`size`、`mid`（= size/2）
  - 函数：`sqrt hypot abs min max round floor ceil`；弧度三角 `sin cos tan asin acos atan atan2`；
    角度三角 `sind cosd tand atan2d`；`radians degrees`；`dist(P, Q)`
  - 名字：var 是数；point 有 `.x .y`；shape 有 `.x .y`（类圆图形是圆心，其余是 bbox 中心）、
    `.left .top .right .bottom .w .h`，类圆图形（circle、ring、arc、sector）还有 `.r`。
    在需要数值的地方直接写类圆图形的名字，得到的是它的半径。

## 3. 点

| 写法 | 含义 |
|---|---|
| `[x, y]` | 每个分量都可以是表达式 |
| `"C"` | 命名点，或某个 shape 的中心 |
| `{"polar": [P, r, deg]}` | 从 P 出发，沿 deg 方向走 r |
| `{"on": 圆, "deg": a}` | 圆周上角度 a 处的点（圆 = 类圆 shape 名、`[P, r]` 或 `{"c":P,"r":r}`） |
| `{"mid": [P, Q]}` / `{"lerp": [P, Q, t]}` | 中点 / 按比例插值 |
| `{"at": P, "dx": a, "dy": b}` | 平移 |
| `{"meet": [[P1, P2], [P3, P4]]}` | 两条直线的交点 |

## 4. 图形 (shapes)

图形写成 `{"种类": 参数, …修饰符}`，也可以直接写名字字符串引用已命名的图形，可以任意嵌套。
"自动构造线"指这个图元会画回构图卡上的线。

### 基本图元

| 种类 | 参数 | 自动构造线 |
|---|---|---|
| `circle` | `[P, r]` 或 `{"c": P, "r": r}` | 圆 + 圆心十字 |
| `ellipse` | `{"c", "rx", "ry", "rot"}` | 椭圆 + 中心 |
| `rect` | `{"x","y","w","h"}` 或 `{"c": P, "w","h"}`；`"r"`：圆角半径，或 `[左上,右上,右下,左下]` | 四条边延长成全幅直线，每个角圆画出圆和圆心 |
| `poly` | `[P, P, P, …]` 或 `{"pts": […]}` | 每条边延长成全幅直线 |
| `ring` | `[P, r_out, r_in]`、`{"c","r","w"}`（外半径 r、环宽 w）或 `{"c","r_out","r_in"}` | 两个圆 + 圆心 |
| `sector` | `{"c","r","from","to"}`：扇形 | 圆 + 两条半径 |
| `arc` | `{"c","r","from","to","w","cap"}`：沿圆弧的带子，r 是中心线半径；`w` 可写 `[粗, …, 细]` 做渐变 | 整圆 + 圆心 |
| `lune` | `{"a": P, "b": Q, "bulge": [s1, s2]}`：两条都经过 a、b 的圆弧夹出的区域 | 两个圆 + 圆心 + 端点 + 弦 |
| `chain` | `[[P, r], [P, r], …]`：一条闭合轮廓，像皮带依次绕过这些圆 | 每个圆 + 圆心，切线延长 |
| `arcgon` | `{"pts": [P…], "edges": [e…]}`：每条边都是圆弧的多边形（帆、盾、叶、鳍）。第 i 条边连接 pts[i] 和 pts[i+1]；边可以是拱高数字（规则同 lune 的 bulge，0 = 直线），或 `{"circle": 圆}`，表示沿这个圆走劣弧（加 `"arc": "major"` 走优弧）。把相邻两个图形的边钉在同心圆上，就得到等宽的缝 | 每条弧边的圆 + 圆心、顶点 |
| `stroke` | `{"pts": [...], "w", "cap", "join", "closed"}`：折线描边，`w` 可渐变 | 中心折线 + 节点 |
| `turtle` | 见下 | 每段弧的整圆和圆心，直线段延长 |
| `path` | SVG path 字符串，或 `{"d": "…"}` | 无：逃生口，尽量别用 |

**lune 的 bulge**：每个值是一条弧的拱高（弦中点到弧顶的距离），**正值鼓向从 a 走到 b 时屏幕上的右手边**。

| a→b 方向 | 正 bulge 鼓向 |
|---|---|
| → 向右 | 下 |
| ↓ 向下 | 左 |
| ← 向左 | 上 |
| ↑ 向上 | 右 |

- `[b, -b]`：对称叶形 / vesica（鱼形），用于叶、花瓣、火焰、杏仁眼。
- `[b1, b2]` 同号且 |b1|>|b2|：新月 / 鳍 / 翅片。
- 单个值 `b`：弓形（一条弧加一条弦）。
- 拱高等于半弦长时是半圆；超过半弦长时弧会大于半圆。

**cap**：`"round"`（默认）、`"butt"`、`"square"`；**join**：`"round"`（默认）、`"miter"`、`"bevel"`。
渐变宽度的描边只支持圆头。

### chain：绕圆的皮带轮廓

```jsonc
{"chain": [
  [[30, 30], 10],     // r > 0：凸，轮廓从外侧包住这个圆（圆在形状内）
  [[70, 30], 10],
  [[50, 45], -8],     // r < 0：凹，轮廓从内侧绕过这个圆（圆在形状外），形成凹口
  [[70, 70], 12],
  [[30, 70], 0]       // r = 0：尖角
]}
```

- 按屏幕上**顺时针**列圆（沿着轮廓走，形状内部在右手边）。写成逆时针也没关系，脚本会自动翻转。
- 相邻两圆之间用公切线连接，整条轮廓 G1 连续。每个圆都会画回构图卡。
- 凸圆必须伸出"前后两个圆的切线"之外，凹圆必须压进去，否则它对轮廓没有贡献，
  皮带会绕它一整圈。脚本会跳过这种圆并在报告里给出 `warning`。
- 小圆配长切线会得到圆角多边形。有机形状要么用大半径圆，要么让圆挨得近一些。

### turtle：相切圆弧链

像海龟作图一样从一点出发、朝一个方向走，每段弧都和上一段相切，适合尾巴、触手、藤蔓和卷曲。

```jsonc
{"turtle": {
  "start": [40, 45], "heading": 150,       // 起点与初始朝向（度）
  "w": [5.6, 1.6],                          // 有 w = 描边（可渐细）；没有 w = 把路径围成的区域填满
  "steps": [
    {"fd": 10},                             // 直走 10（也可写 "line": 10）
    {"arc": 12, "turn": 30},                // 半径 12 的弧，转 30°；正 = 顺时针（右转），负 = 左转
    {"spiral": 7, "quarters": 4},           // 黄金螺旋：4 段 90° 弧，半径 7, 7/φ, 7/φ², …
    {"spiral": 6, "ratio": 0.7, "quarters": 3, "dir": -1, "sweep": 90},
    {"goto": [60, 40]},                     // 直线走到某点（会折角）
    {"heading": 90}, {"turn": -45}          // 原地改朝向（折角）
  ],
  "cap": "round", "close": false
}}
```

想让卷曲向外翻，先确认转向：朝左 (180°) 走、顺时针转，就会向上卷 (270°)。

### 组合

| 种类 | 参数 | 说明 |
|---|---|---|
| `union` | `[A, B, …]` | 并 |
| `subtract` | `[A, B, …]` | A 减去其余 |
| `intersect` | `[A, B, …]` | 交，例如两圆相交得 vesica |
| `xor` | `[A, B]` | 异或 |
| `hull` | `[A, B, …]` | 凸包。两圆的 hull 就是用外公切线连起来的"胶囊"，它的直边会延长成构造线 |
| `offset` | `{"shape": X, "d": d}` | 整体外扩 (d>0) 或内缩 (d<0)，圆角连接 |

### 变换（只支持保持圆还是圆的相似变换）

| 种类 | 参数 |
|---|---|
| `mirror` | `{"shape": X, "x": 50}` 竖轴镜像，或 `{"shape": X, "y": 50}` 横轴镜像；`"keep": true`（默认）同时保留原件；会自动画对称轴虚线 |
| `rotate` | `{"shape": X, "deg": a, "about": P, "copy": false}`；about 默认画板中心 |
| `move` | `{"shape": X, "by": [dx, dy], "copy": false}` |
| `scale` | `{"shape": X, "k": k, "about": P, "copy": false}` |
| `repeat` | `{"shape": X, "n": 5, "about": P, "step": 72, "start": 0}`：旋转阵列，step 默认 360/n |

## 5. 修饰符

可以加在任意图形节点上：

- `"blend": r`：只把凹角补成半径 r 的圆弧（形态学闭运算），凸弧保持不变。用于把几段 hull 或几个圆接成一块顺滑的体积。
  距离小于 2r 的缝也会被填上。
- `"round": r`：给这个图形的所有凸角和凹角倒半径 r 的圆角。比 r 还细的部位会被抹掉。
- `"guide": false`：不画它的构造线；`"circles"`：只画圆和圆心；`"lines"`：只画直线。

## 6. ink：加、挖、裁

`ink` 按顺序执行，相当于画家算法：

| 步骤 | 效果 |
|---|---|
| `"name"` 或直接写图形节点 | 加上（并集） |
| `{"add": X, "gap": g}` | 先从已有墨迹里挖掉 X 外扩 g 的区域，再加上 X，形成一条宽 g 的米白缝。前景部件压后景时用它。构图卡上，X 的每个圆（r≥2）都会多画一个半径 r+g 的同心圆，表示缝的外沿 |
| `{"cut": X}` | 挖掉 |
| `{"clip": X}` | 只保留与 X 相交的部分 |

每一步都可以加 `"guide": false`，把这一步用到的图形从构图卡上隐去。

常见顺序：后景体块 → 前景部件（带 gap）→ 挖孔（眼睛、窗户）→ 孔里的小件（瞳孔）→ 切地面。

## 7. 额外构造线 (guides)

只画在构图卡上，不影响形状。用来补充讲解比例关系。

| 写法 | 画什么 |
|---|---|
| `{"circle": 圆}` | 构造圆 |
| `{"line": [P, Q]}` | 过两点的全幅直线 |
| `{"seg": [P, Q]}` | 线段 |
| `{"hline": y}` / `{"vline": x}` | 水平 / 竖直全幅线 |
| `{"axis": true}` 或 `{"axis": x}`，`{"haxis": y}` | 对称轴虚线 |
| `{"angle": [P, deg]}` | 过 P、方向为 deg 的直线 |
| `{"tangent": [圆A, 圆B], "which": "outer"}` | 两圆的公切线（outer / inner / both）及切点 |
| `{"tangent_at": [圆, deg]}` | 圆在某角度处的切线 |
| `{"radius": [圆, deg]}` 或 `{"radius": [P, r, deg]}` | 半径线 + 端点 |
| `{"point": P}` | 十字标记 |
| `{"show": "shape"}` | 画出某个没用在 ink 里的图形的构造线 |
| `{"outline": "shape"}` | 用虚线画出某个图形的轮廓 |

## 8. 命令行

```bash
python3 scripts/logo.py spec.json -o out/dir   # 默认输出到 spec 旁边、以 name 命名的目录
python3 scripts/logo.py spec.json --scale 2    # 海报和构图卡输出 2160×2700
python3 scripts/logo.py spec.json --no-png     # 只要 SVG
python3 scripts/logo.py spec.json --all-guides # 构图卡画出全部构造（调试用）
python3 scripts/logo.py spec.json --compare old.png          # 规整现有图标：另出 compare.png（原图 | 规整后 | 叠加）
python3 scripts/logo.py spec.json --icon-pad 0 --icon-png 1024  # icon.svg 满版无边距，并输出 1024px 的 icon.png
python3 scripts/logo.py --svg other.svg -o review/            # 评审外部生成的 SVG：海报、小尺寸测试、体检，无构图卡
python3 scripts/measure.py old.png                               # 测量现有图标的部件尺寸、间距、比例
```

**icon.svg 的写法：** 最终轮廓逐段和所有构造圆比对（包括 gap 的同心圆）。沿某个圆的连续部分写成 SVG 圆弧
`A r r 0 large sweep x y`，端点精确投影到圆上，超过 120° 的弧会切成几段，避免接近半圆时渲染器对圆心的判断不稳定。
直段写成 `L`。剩下的（blend/soften/round 的倒角、渐细描边的边缘）写成折线。
`report.txt` 第一行给出三者在轮廓长度中的占比。

报错会指出是哪个 shape 或哪个 ink 步骤出了问题，例如 `in shape 'fin': cannot evaluate 'R - w2': name 'w2' is not defined`。
